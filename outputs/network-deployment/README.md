# Aurora fictional network deployment

The current deliverable is the [ten-sheet deployment and operations example](reference-inspired/README.md). It includes device models and IP addresses, both cable endpoint ports, Excalifont, editable equipment illustrations, branch interface/SSID/port schedules, WAN/NAT documentation and revision control.

The `detailed` folder retains the earlier eight-sheet version. Files in this directory's root retain the initial two-frame overview and its test evidence. These are historical iterations. The `iterations` folder also retains the rejected box layout and an intermediate handwritten draft.
